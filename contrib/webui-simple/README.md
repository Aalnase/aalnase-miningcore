# Simple MFLEX WebUI

A small dependency-free HTML/CSS/JavaScript dashboard for the Ubuntu 24 MFLEX Miningcore installer.

This WebUI is original project code for this fork. It intentionally avoids vendored third-party frontend templates and uses browser-native APIs only. It talks to Miningcore through the local Nginx `/api/` reverse proxy configured by `contrib/install/install-webui-simple.sh`.
