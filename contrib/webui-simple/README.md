# Simple MFLEX WebUI

A small dependency-free HTML/CSS/JavaScript dashboard for the Ubuntu 24 MFLEX Miningcore installer.

This WebUI is original project code for this fork and intentionally does not vendor or copy TheRetroMike/minernl Miningcore.WebUI assets. It uses browser-native APIs only and talks to Miningcore through the local Nginx `/api/` reverse proxy configured by `contrib/install/install-webui-simple.sh`.
